# Модуль 1: Задания по Java
Этот репозиторий содержит решения для Задач 1.1 и 1.2.

## Задача 1.1: Подсчет вхождений / статистика символов
**Формулировка задачи:** Написать программу, которая вводит с консоли строку русского текста, после чего выводит по каждой гласной букве количество раз, которое эта буква встретилась во введённой строке.

**Решения:**
*   **Процедурный стиль:** `Task1_1/src/Task1.java`
*   **ООП стиль:** `Task1_1/src/SymStats.java` и `Task1_1/src/MainStats.java`

## Задача 1.2: Баланс скобок
**Формулировка задачи:** Написать программу, которая вводит строку русского текста, после чего проверяет сбалансированность скобок (4 типов: круглые, фигурные, квадратные, угловые). В случае нарушения баланса выдать информацию о месте возникновения ошибки.

**Решения:**
*   **Процедурный стиль:** `Task1_2/src/BracketsTask1.java`
*   **ООП стиль:** `Task1_2/src/StringValidator.java`, `Task1_2/src/BracketsValidator.java` и `Task1_2/src/MainBrackets.java`
